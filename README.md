# Contact Book - Python GUI App

A simple and user-friendly Contact Book application built with Python's Tkinter library. This desktop app allows you to store, view, update, and delete contact details with a clean graphical interface. Perfect for beginners learning GUI development in Python.

---

##  Features

- 📇 Add new contacts (Name, Phone, Email, Address)
- 🔍 Search for existing contacts
- 📝 Update contact details
- ❌ Delete unwanted contacts
- 💾 Data stored persistently (using file or database - depending on your implementation)
- 🖥️ Lightweight, responsive, and beginner-friendly interface using Tkinter
  
---

## 🛠 Tech Stack

- **Language**: Python 3.10
- **Tkinter**: (comes pre-installed with Python)
